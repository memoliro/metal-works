# JSM Metal Works

Free metal-working pattern tools — no account, no upload, works in the browser.

## Tools
- **Pipe insulation cladding** — gored elbow (end + middle gores), straight jacket, concentric reducer, flat end cap. NPS presets, lap allowances, 16-division ordinate tables, sheet area + weight.
- **Saddle / wraparound template** — any branch angle, ordinates + header-hole outline.
- **Pipe offset calculator** — simple + rolling offsets.
- **Pipe sizes** — ASME B36.10 NPS table + EN 10220 Series 1 toggle (DN15–DN600).
- **Multi-bend sheet-metal flat patterns** — coming next (bend allowance / K-factor, presets, 1:1 print).

## Output
- 1:1 print on tiled A4 / Letter / A3 with overlap lines + 100 mm scale-check bar
- True-size SVG / DXF download
- On-screen 1:1 check (hold a ruler to the screen, slide zoom until the 100 mm bar measures 100 mm)
- 3D spin preview per tool (drag to spin, auto-rotates)

## Deploy
Static single page (`index.html`). Any static host works; live site runs on Cloudflare Pages from this repo.

## Local use
Open `index.html` in a browser. No build step, no server.
